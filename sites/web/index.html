把一篇 PDF 拖进来，让它接受回查。

工作台先抽取证据卡，逐字回查每一句引文是否真的在那一页； 只有通过回查的卡片才允许进入写作，笔记写完后还要逐段审计论断——引用对不上就阻断。 PDF 由浏览器本地解析，链路在本页运行，不上传任何文件。

支持拖拽上传，仅处理带文字层的 PDF。

    链路说明

    cards 逐字回查 → note 只用通过卡片写作 → audit 逐段核查 → gate 全有据才放行 → archive 原子落盘。

    回查

    证据卡的引文必须能在对应页原文逐字定位，失败卡片不进入写作。

    审计

    笔记逐段列出事实性陈述，标四态；引用对不上即阻断。

    门禁

    全部 supported 才归档；有待限定论断转人工复核。

    隐私

    PDF 由浏览器本地解析，链路全离线运行，文件不离开本机。
